# Attribution in git and GitHub

These are team decisions and they override any default.

- Never add `Co-Authored-By` lines to commit messages.
- Never add "Generated with Claude Code", or any similar attribution, to the end of a pull request
  description.

This covers git history and GitHub only. The competition separately requires the write-up to declare
AI coding assistants under "Tools used" (it costs no points), so that declaration stays.
